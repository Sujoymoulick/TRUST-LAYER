The stunning, high-performance user interface for the TrustLayer platform. Built with a modern, "Brutalist" design aesthetic for maximum visual impact.

---

## ✨ Features

- **Interactive Dashboard**: Real-time trust score visualization and graph data exploration.
- **Identity Vault**: Securely manage and link professional/financial identities.
- **API Management**: Console for generating and monitoring production access.
- **Modern UI**: Custom-built design system with fluid animations (Framer Motion) and brutalist elements.
- **Secure Integration**: Direct connection to the TrustLayer Backend API.

---

## 🛠️ Tech Stack

- **Framework**: React 18 (Vite)
- **Language**: TypeScript
- **Styling**: Tailwind CSS + Custom Brutalist CSS
- **Icons**: Lucide React
- **Animations**: Framer Motion
- **Auth**: Supabase Auth

---

## 🏁 Quick Start

### 1. Environment Setup
Create a `.env` file in the `/frontend` directory:

```env
VITE_API_BASE_URL=https://your-backend-url.onrender.com/api/v1
VITE_SUPABASE_URL=your-url
VITE_SUPABASE_ANON_KEY=your-anon-key
VITE_TURNSTILE_SITE_KEY=your-key
```

### 2. Install & Run
```bash
npm install
npm run dev
```
